POVIJEST HTML-A

Od jednostavnog teksta do modernog Weba

Sve je počelo 1989. godiine u CERN-u. Tim Berners-Lee je osmislio sustav koji bi istraživaćima omogućio dijeljenje dokumenata. Taj sustav postao je poznat kao World Wide Web

Jezik koji je definirao strukturu elemenata nazvan je HTML (HyperText Markup Language).Njegova osnovna svrha bila je semantički opisati strukturu dokumenta, a ne njegov izgled.

Ključne verzije

01. HTML 1.0 (1991)

Prva neslužbena verzija. Sadržavala je samo 18 tragova.

02. HTML 2.0 (1995)

Prvi službeni standard (RFC 1866).

03. HTML 3.2 (1997)

Uvedene tablice i apieti. "Rat pobjednika" ja bio u punom jeku.

04. HTML 4.01 (1999)

Dominantna verzija gotovo desetljeće. Odvajanje stila(CSS) od sadržaja.

05. HTML5 (2014)

Revolucija. Multimedija bez dodataka i semantički elementi.

>

Struktura Dokumenta

Osnovna struktura HTML5 dokumenta izgleda ovako:

                <!DOCTYPE html>
                <html lang="hr>

                <head>
                <title>Naslov</title>
                <head>
                <body>
                <p>Pozdrav svijete!</p>
                </body>
                </html>

Da biste spremili ovaj kod, pritisnite Ctrl+S na tipkovnici.

Važni pojmovi

HTTP HyperText Tranfer Protocol - protokol za prijenos podataka

URI Uniform Resource Identifier - adresa resursa na webu.
